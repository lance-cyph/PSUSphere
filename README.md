# 🎓 PSUSphere

> 🌐 **Connect. Organize. Manage.**

A Django-based student organization management system designed to manage **students, colleges, programs, organizations, and memberships**.

## ✨ Features

* 🏫 College Management
* 📚 Program Management
* 👨‍🎓 Student Management
* 🏢 Organization Management
* 🤝 Membership Management
* 🛠️ Django Admin Dashboard
* 🎲 Fake Data Generation with Faker

## 🛠️ Built With

**Python • Django • SQLite • Faker • Git & GitHub**
